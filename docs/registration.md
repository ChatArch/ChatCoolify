# 注册与邀请

Coolify 控制服务器、容器、域名、数据库和环境变量。生产实例应关闭公开注册，只接受管理员明确邀请的成员。

## 邀请流程

1. 管理员登录 Coolify。
2. 切换到目标 Team。
3. 打开 **Team → Members**。
4. 填写受邀邮箱与角色。
5. 选择 **Generate link**，或在事务邮件配置完成后选择 **Send email**。
6. 单独将邀请链接发送给受邀人。
7. 在 **Pending invitations** 中复核、撤销或重新创建邀请。

## 角色选择

| 角色 | 能力 | 建议对象 |
| --- | --- | --- |
| Owner | 管理 Owner 与团队最高权限 | 平台维护者 |
| Admin | 管理团队资源、部署和一般成员 | 指定的项目负责人 |
| Member | 参与被授权资源 | 外部协作者默认值 |

!!! danger
    Team 角色隔离的是 Coolify 控制面，不是独立虚拟机。不要向外部成员提供宿主机 SSH、Docker socket、sudo、特权容器或任意主机卷挂载能力。

## 结束协作

- 从 Team 移除成员并撤销未使用邀请。
- 撤销该成员创建的 API Token。
- 检查 Git Provider、Webhook、共享变量和外部服务密钥。
- 对已接触的运行时密钥执行轮换。
